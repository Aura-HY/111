## 新建文件

| 对比项                  | GitHub                                                       | GitLab                                                       |
| :---------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **入口**                | 文件列表上方 `Add file` 下拉菜单 → `Create new file`         | 目录名旁边 `+` 图标下拉菜单 → `New file`                     |
| **新建文件界面**        | 在线编辑器界面                                               | Web Editor 界面                                              |
| **文件名输入**          | 用 `/` 创建子目录                                            | 单独创建目录，创建后会自动在里面加一个 `.gitkeep` 文件       |
| **编辑器视图**          | 有 `Edit` 和 `Preview` 两个视图（Preview 主要支持 md 文件预览，其他类型文件展示效果与 Edit 视图一致，都有对应代码高亮） | 只有一个编辑视图                                             |
| **代码高亮**            | 支持根据代码文件后缀（文件类型）进行不同高亮                 | 支持根据代码文件后缀（文件类型）进行不同高亮                 |
| **代码格式化/显示设置** | 支持三项设置： • **Spaces**：选择缩进字符类型（Spaces/Tabs） • **缩进大小**：数字，表示每次缩进的空格数或 Tab 等效宽度（常见值：2、4、8） • **No wrap**：文本换行模式（No wrap/Soft wrap） | 只支持修改文本换行模式（No wrap/Soft wrap）                  |
| **提交位置**            | 顶部                                                         | 底部                                                         |
| **提交信息**            | 提交弹窗中填写，可 AI 自动生成、可不填，默认自动填充提交信息，清空后仍自动填充 | 直接在编辑器底部填写，默认自动填充，**必填**                 |
| **扩展描述**            | 支持，可 AI 生成                                             | 不支持                                                       |
| **提交方式**            | 选择提交到当前分支或新建分支                                 | 目标分支默认填入当前分支；若手动改为新分支名，会出现"是否以此分支创建合并请求"勾选项： • 取消：自动创建新分支并 push • 勾选：进入创建新的合并请求界面 |
| **取消操作**            | 浏览器弹窗提示                                               | 弹出二次确认弹窗                                             |
